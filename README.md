# Insurance Renewal Bot

Ежедневный бот для напоминания о продлении договоров страхования.

## Как это работает
Скрипт `main.py` запускается через GitHub Actions каждый день в 09:00 МСК. Он скачивает таблицу с Яндекс.Диска, находит договоры, до окончания которых осталось 2 месяца, и отправляет письмо на указанные адреса.

## Настройка
Все параметры задаются через `Secrets` в настройках GitHub Actions.
